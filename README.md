# 💡 myGeeKy ideas

Ideas, problems and questions about [myGeeKy](https://github.com/AlsammanAlsamman/myGeeKy), mostly sent from the **💡** button in the myGeeKy panel (or `mygeeky idea` in the terminal).

- **Have an idea?** Click 💡 in the panel, or [open an issue](https://github.com/AlsammanAlsamman/myGeeKy-ideas/issues/new).
- **Something not working?** Choose *Problem* and keep "include version info" ticked. If myGeeKy saved an error report, attach that file.
- 👍 an issue to vote for it.

Everything here is public, so please don't paste tokens or private data.
